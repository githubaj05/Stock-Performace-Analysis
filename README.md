# Indian Oil Stock Analysis | Power BI

## About the Project

This project analyzes Indian Oil's historical stock performance from 2018 to 2023 using Microsoft Power BI. The dashboard helps explore stock price movements, returns, volatility, drawdowns, and trading activity through interactive charts, KPI cards, and filters.

## How the Project Improved

The initial dashboard focused mainly on Open, High, Low, and Close prices, along with trading volume and time-based trends.

I later improved the report by organizing the price analysis into a dedicated page and adding separate pages for return analysis, volatility, drawdowns, trading activity, and performance insights. I also used DAX measures to calculate important financial metrics.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel/CSV dataset

## Dashboard Pages

### 1. Stock Overview

Provides a summary of stock performance using key metrics, yearly comparisons, and closing price trends.

### 2. Price and Trend Analysis

Explores Open, High, Low, and Close prices across different time periods.

### 3. Return and Performance Analysis

Analyzes price changes and percentage returns across selected periods.

### 4. Return Volatility Analysis

Examines fluctuations in daily returns and the average daily price range.

### 5. Drawdown Analysis

Tracks declines from previous price peaks to understand historical downside movements.

### 6. Trading Activity Analysis

Examines trading volume across years, quarters, and months.

### 7. Performance Summary and Insights

Combines yearly performance, monthly return patterns, quarterly returns, and key findings.
